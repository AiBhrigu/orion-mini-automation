[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)
[![ICP](https://img.shields.io/badge/DFINITY-ICP-blue)](https://dfinity.org/)

## Шаги установки 🚀

1. `dfx start --background` — Запусти локальную среду
2. `make build` — Собери проект
3. `make deploy` — Задеплой канистру

## Структура 📂

- `scripts/` — Скрипты автоматизации
- `config/` — Конфигурация DFX и окружения
- `src/` — Исходники (Motoko, Rust, Frontend)
- `docs/` — Документация
- `Makefile` — Удобные команды
